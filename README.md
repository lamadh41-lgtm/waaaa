# ProSpace — مساحتك الاحترافية

واجهة ويب احترافية لتنظيم ملفاتك محلياً داخل المتصفح.

## المميزات

- قوائم مخصصة (ألعاب، شغل، مذاكرة، ميديا...) + إمكانية إضافة قوائم جديدة
- رفع أي نوع ملفات (فيديو، PDF، صور، برامج، مستندات، أرشيفات...)
- سحب وإفلات (Drag & Drop)
- حفظ محلي كامل باستخدام IndexedDB (الملفات تبقى حتى بعد إغلاق المتصفح)
- بحث وترتيب وعرض شبكة أو قائمة
- تصميم داكن حديث ومريح

## طريقة الاستخدام

1. فك الضغط عن الملف
2. افتح `index.html` في المتصفح (Chrome / Edge / Firefox)
3. ابدأ برفع ملفاتك وتنظيمها

## ملاحظات

- كل البيانات تُحفظ محلياً على جهازك فقط
- الحد الأقصى المقترح لكل ملف: 50 ميجابايت
- لا يحتاج إنترنت بعد فتح الصفحة لأول مرة
